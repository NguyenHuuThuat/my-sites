AHàm số bậc nhất
Bài 1Thông hiểu
Hai đường thẳng \((d_1), (d_2)\) như hình vẽ, mỗi đường đi qua hai điểm đã đánh dấu.

Lời giải

a) Gọi phương trình đường thẳng có dạng \(y = ax + b\).

\((d_1)\) đi qua \((0;0)\) và \((2;4)\): thay \((0;0)\Rightarrow b=0\); thay \((2;4)\Rightarrow 4 = 2a \Rightarrow a = 2\). Vậy \((d_1): y = 2x\).

\((d_2)\) đi qua \((0;3)\) và \((3;0)\): thay \((0;3)\Rightarrow b = 3\); thay \((3;0)\Rightarrow 0 = 3a + 3 \Rightarrow a = -1\). Vậy \((d_2): y = -x + 3\).

b) Hoành độ giao điểm: \(2x = -x + 3 \Rightarrow 3x = 3 \Rightarrow x = 1 \Rightarrow y = 2\).

Vậy \(A(1;\,2)\).

c) \((d_1)\) cắt \(Ox\): \(2x = 0 \Rightarrow B(0;0)\) (chính là gốc \(O\)). \((d_2)\) cắt \(Ox\): \(-x+3=0 \Rightarrow C(3;0)\).

Tam giác \(ABC\) có \(BC\) nằm trên \(Ox\), độ dài \(BC = 3\); chiều cao hạ từ \(A\) xuống \(Ox\) bằng \(|y_A| = 2\).

\(S_{ABC} = \dfrac12 \cdot BC \cdot h = \dfrac12 \cdot 3 \cdot 2 = 3\) (đơn vị diện tích).

Bài 2Vận dụng
\(y = (m-1)x + 2m - 3\), với \(m\) ≠ \(1\).

Lời giải

a) Đồ thị qua \(P(1;2)\) nghĩa là thay \(x=1, y=2\): \((m-1)\cdot 1 + 2m - 3 = 2\)

\(\Rightarrow m - 1 + 2m - 3 = 2 \Rightarrow 3m - 4 = 2 \Rightarrow 3m = 6 \Rightarrow m = 2\) (thoả \(m\) ≠ \(1\)).

Vậy \(m = 2\).

b) Hai đường thẳng song song khi hệ số góc bằng nhau và tung độ gốc khác nhau:

Điều kiện: \(m - 1 = 3\) và \(2m - 3\) ≠ \(-1\). Từ \(m - 1 = 3 \Rightarrow m = 4\); khi đó \(2m - 3 = 5\) ≠ \(-1\) (thoả mãn).

Vậy \(m = 4\).

c) Biến đổi để tách theo \(m\): \(y = (m-1)x + 2m - 3 = mx - x + 2m - 3 = m(x + 2) - x - 3\).

Giá trị của \(y\) không phụ thuộc \(m\) khi hệ số của \(m\) bằng 0, tức là \(x + 2 = 0 \Rightarrow x = -2\).

Khi đó \(y = -x - 3 = -(-2) - 3 = -1\).

Vậy đồ thị luôn đi qua điểm cố định \(I(-2;\,-1)\) với mọi \(m\).

Bài 3Thông hiểu
Thuê 3 giờ trả 65 nghìn; thuê 5 giờ trả 95 nghìn; \(y\) là hàm bậc nhất của \(x\).

Lời giải

a) Đặt \(y = ax + b\). Từ dữ kiện: thuê 3 giờ trả 65 và thuê 5 giờ trả 95:

\(\begin{cases} 3a + b = 65 \\ 5a + b = 95 \end{cases}\)   Trừ vế theo vế: \(2a = 30 \Rightarrow a = 15 \Rightarrow b = 65 - 3\cdot 15 = 20\).

Vậy \(y = 15x + 20\) (nghìn đồng).

b) Với \(x = 8\): \(y = 15\cdot 8 + 20 = 140\) (nghìn đồng).

c) Có 140 nghìn: \(15x + 20 \le 140 \Rightarrow 15x \le 120 \Rightarrow x \le 8\).

Vậy thuê được nhiều nhất 8 giờ.

BHàm số y = ax²
Bài 4Thông hiểu
Đồ thị \(y = ax^2\) đi qua các điểm đã đánh dấu trên hình.

Lời giải

a) Đồ thị đi qua điểm \((2;2)\), thay vào \(y = ax^2\): \(2 = a\cdot 2^2 = 4a \Rightarrow a = \dfrac12\).

Vậy \(y = \dfrac12 x^2\). (Kiểm tra điểm \((-2;2)\): \(\dfrac12\cdot(-2)^2 = 2\) ✓)

b) Xét \(M(-4;8)\): \(\dfrac12\cdot(-4)^2 = \dfrac12\cdot 16 = 8\), đúng bằng tung độ, nên \(M\) thuộc đồ thị.

Xét \(N(3;4)\): \(\dfrac12\cdot 3^2 = \dfrac{9}{2} = 4{,}5\) ≠ \(4\), nên \(N\) không thuộc đồ thị.

c) Điểm có tung độ 8: \(\dfrac12 x^2 = 8 \Rightarrow x^2 = 16 \Rightarrow x = \pm 4\).

Vậy hai điểm cần tìm là \((4;8)\) và \((-4;8)\).

Bài 5Vận dụng
\((P): y = x^2\) và \((d): y = -x + 2\).

Lời giải

a) Phương trình hoành độ giao điểm: \(x^2 = -x + 2 \Rightarrow x^2 + x - 2 = 0\).

\((x + 2)(x - 1) = 0 \Rightarrow x = -2\) hoặc \(x = 1\).

Với \(x = -2 \Rightarrow y = (-2)^2 = 4\); với \(x = 1 \Rightarrow y = 1\).

Hai giao điểm: \(A(-2;\,4)\) và \(B(1;\,1)\).

b) \(AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2} = \sqrt{(1-(-2))^2 + (1-4)^2} = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2}\).

c) Xét phương trình hoành độ giao điểm của \((P)\) và \(y = -x - 1\): \(x^2 = -x - 1 \Rightarrow x^2 + x + 1 = 0\).

\(\Delta = 1^2 - 4\cdot 1\cdot 1 = -3 < 0\), suy ra phương trình vô nghiệm.

Vậy đường thẳng \(y = -x - 1\) không cắt \((P)\).

Bài 6Vận dụng
\((P): y = ax^2\) đi qua \(A(-2;6)\).

Lời giải

a) Thay \(A(-2;6)\): \(6 = a\cdot(-2)^2 = 4a \Rightarrow a = \dfrac{3}{2}\). Vậy \((P): y = \dfrac32 x^2\).

b) \(B(m;24) \in (P)\): \(24 = \dfrac32 m^2 \Rightarrow m^2 = 16 \Rightarrow m = \pm 4\).

c) Điểm có tung độ gấp đôi hoành độ nghĩa là \(y = 2x\). Kết hợp \(y = \dfrac32 x^2\):

\(\dfrac32 x^2 = 2x \Rightarrow 3x^2 = 4x \Rightarrow x(3x - 4) = 0 \Rightarrow x = 0\) (loại vì trùng gốc toạ độ) hoặc \(x = \dfrac43\).

Với \(x = \dfrac43 \Rightarrow y = 2\cdot\dfrac43 = \dfrac83\).

Vậy điểm cần tìm là \(\left(\dfrac43;\ \dfrac83\right)\).

CPhương trình bậc hai & định lí Vi-ét
Bài 7Vận dụng cao
\(x^2 - 2(m+1)x + m^2 + 2 = 0\).

Lời giải

a) Tính \(\Delta'\) (với \(b' = -(m+1)\)):

\(\Delta' = (m+1)^2 - (m^2 + 2) = m^2 + 2m + 1 - m^2 - 2 = 2m - 1\).

Phương trình có hai nghiệm phân biệt \(\iff \Delta' > 0 \iff 2m - 1 > 0 \iff m > \dfrac12\).

b) Với \(m > \dfrac12\), theo định lí Vi-ét: \(x_1 + x_2 = 2(m+1)\), \(\;x_1 x_2 = m^2 + 2\).

\(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 4(m+1)^2 - 2(m^2 + 2)\)

\(= 4m^2 + 8m + 4 - 2m^2 - 4 = 2m^2 + 8m\).

Yêu cầu \(x_1^2 + x_2^2 = 10\): \(2m^2 + 8m = 10 \Rightarrow m^2 + 4m - 5 = 0 \Rightarrow (m - 1)(m + 5) = 0\).

\(\Rightarrow m = 1\) hoặc \(m = -5\). Đối chiếu điều kiện \(m > \dfrac12\): loại \(m = -5\).

Vậy \(m = 1\).

Bài 8Thông hiểu
\(2x^2 - 5x - 3 = 0\), hai nghiệm \(x_1, x_2\) (không giải phương trình).

Lời giải

Phương trình có \(a = 2, b = -5, c = -3\). Vì \(a\cdot c = -6 < 0\) nên luôn có hai nghiệm phân biệt.

a) Theo Vi-ét: \(S = x_1 + x_2 = -\dfrac{b}{a} = \dfrac{5}{2}\); \(\;P = x_1 x_2 = \dfrac{c}{a} = -\dfrac{3}{2}\).

b) \(x_1^2 + x_2^2 = S^2 - 2P = \dfrac{25}{4} - 2\cdot\left(-\dfrac32\right) = \dfrac{25}{4} + 3 = \dfrac{37}{4}\).

c) \(\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2} = \dfrac{S}{P} = \dfrac{5/2}{-3/2} = -\dfrac{5}{3}\).

d) \((x_1 - x_2)^2 = S^2 - 4P = \dfrac{25}{4} - 4\cdot\left(-\dfrac32\right) = \dfrac{25}{4} + 6 = \dfrac{49}{4}\).

Bài 9Vận dụng
\(3x^2 - 7x + 2 = 0\), lập phương trình có nghiệm \(y_1 = x_1 + 1,\ y_2 = x_2 + 1\).

Lời giải

Theo Vi-ét cho phương trình \(3x^2 - 7x + 2 = 0\): \(S = x_1 + x_2 = \dfrac{7}{3}\), \(\;P = x_1 x_2 = \dfrac{2}{3}\).

Tính tổng hai nghiệm mới: \(y_1 + y_2 = (x_1 + 1) + (x_2 + 1) = S + 2 = \dfrac{7}{3} + 2 = \dfrac{13}{3}\).

Tính tích hai nghiệm mới: \(y_1 y_2 = (x_1 + 1)(x_2 + 1) = x_1 x_2 + (x_1 + x_2) + 1 = P + S + 1 = \dfrac{2}{3} + \dfrac{7}{3} + 1 = 3 + 1 = 4\).

Phương trình cần tìm nhận \(y_1, y_2\) làm nghiệm: \(y^2 - (y_1 + y_2)y + y_1 y_2 = 0\), tức

\(y^2 - \dfrac{13}{3}y + 4 = 0\).

Nhân hai vế với 3 để hệ số nguyên: \(3y^2 - 13y + 12 = 0\).

Bài 10Vận dụng cao
Tìm chỗ sai trong bài làm về phương trình \(x^2 - 2mx + m^2 + 1 = 0\) với điều kiện \(x_1 + x_2 = 4\).

Lời giải

Chỗ sai: Bạn đó đã áp dụng định lí Vi-ét ngay mà chưa kiểm tra điều kiện để phương trình có nghiệm (\(\Delta \ge 0\)). Định lí Vi-ét chỉ dùng được khi phương trình thực sự có nghiệm.

Giải lại cho đúng: Xét \(\Delta'\) với \(b' = -m\):

\(\Delta' = m^2 - (m^2 + 1) = -1 < 0\) với mọi \(m\).

Do \(\Delta' < 0\) với mọi \(m\) nên phương trình vô nghiệm với mọi giá trị của \(m\). Vì thế không tồn tại hai nghiệm \(x_1, x_2\) để nói tới điều kiện \(x_1 + x_2 = 4\).

Kết luận: Không có giá trị \(m\) nào thoả mãn. (Đáp số \(m = 2\) của bạn đó là sai.)
