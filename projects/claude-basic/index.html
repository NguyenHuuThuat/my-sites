Dùng Claude như một
người vận hành thành thạo Một cuốn sổ tay tra cứu đầy đủ về mọi bề mặt của Claude — Chat, Code, Cowork, Design — và cách khai thác từng tính năng cho công việc Data Science, AI engineering và phát triển web.

Claude không phải một sản phẩm duy nhất mà là một hệ các bề mặt chia sẻ chung lõi mô hình. Hiểu đúng "việc nào dùng bề mặt nào" là khác biệt lớn nhất giữa người dùng casual và người dùng hiệu quả. Cuốn này đi từ bản đồ tổng quan đến từng tính năng, kèm playbook cụ thể cho nghề của bạn.

4 bề mặt chính 3 mô hình hiện hành Opus 4.8 · Sonnet 4.6 · Haiku 4.5 cập nhật 06/2026

Cách đọc: mỗi mục được đánh số như một "plate" trong sổ tay kỹ thuật. Cột trái là mục lục cố định — bấm để nhảy. Nội dung viết dạng tra cứu: đọc lướt được, nhưng đủ sâu để học từng tính năng.

01

Định hướng

Bản đồ hệ sinh thái: việc nào dùng bề mặt nào

Cùng một lõi mô hình, nhưng bốn bề mặt khác nhau ở quyền hạn và nơi nó chạy. Chọn sai bề mặt là nguyên nhân phổ biến nhất khiến người ta thấy Claude "kém hiệu quả".

Bề mặt 1 · chat

Claude web / mobile / desktop

Giao diện hội thoại. Claude trả lời, viết, phân tích, tạo artifact (tài liệu/biểu đồ/app), nhưng không tự đụng vào máy hay repo của bạn trừ khi bạn bật công cụ. Đây là nơi để hỏi, brainstorm, soạn thảo, tạo file.

Bề mặt 2 · code

Claude Code

Agent lập trình sống trong terminal/IDE/desktop/browser. Đọc cả codebase, sửa nhiều file, chạy lệnh, chạy test, mở PR. Bạn giao mục tiêu, nó tự lập kế hoạch và thực thi — bạn duyệt kết quả.

Bề mặt 3 · cowork

Claude Cowork

Cùng kiến trúc agent với Code nhưng cho việc tri thức phi lập trình, trên desktop. Trỏ vào một thư mục: nó đọc/sửa/tạo file thật, dựng báo cáo, dọn dữ liệu, điều phối sub-agent.

Bề mặt 4 · design

Claude Design

Canvas trực quan. Mô tả bằng lời → Claude dựng UI/prototype/slide bằng HTML/CSS/JS thật, đọc design system của bạn để bám brand, rồi export hoặc bàn giao thẳng cho Claude Code.

Cây quyết định

Nguyên tắcChat để nghĩ và tạo, agent (Code/Cowork) để làm. Nếu bạn thấy mình copy–paste qua lại nhiều lần giữa chat và máy của mình, đó là tín hiệu nên chuyển sang Code hoặc Cowork để Claude tự thao tác.
02

Nền tảng

Mô hình & gói dịch vụ

Hai trục độc lập cần tách bạch: mô hình (năng lực vs tốc độ/chi phí) và gói (bao nhiêu dung lượng dùng + mở khoá tính năng nào).

Các mô hình hiện hành

Trong app, chế độ Auto sẽ tự chọn mô hình theo độ khó; bạn có thể chọn tay khi cần. Quy tắc đơn giản: dùng Sonnet 4.6 cho phần lớn việc; nâng lên Opus 4.8 khi bài toán cần suy luận sâu, kiến trúc, hoặc agent chạy dài; hạ xuống Haiku 4.5 cho việc khối lượng lớn cần nhanh/rẻ (phân loại, trích xuất, tóm tắt hàng loạt).

Lưu ý: trên Opus còn một lớp "Mythos" (Mythos 5 / Fable 5) chưa mở công khai. Nếu cần thông tin mới nhất, xem thông báo chính thức của Anthropic — bản hướng dẫn này có thể chưa cập nhật trạng thái đó.

03

Bề mặt nền tảng

Claude web/app — và bộ tính năng cốt lõi

Đây là nơi bạn dành phần lớn thời gian. Bên dưới ô chat là một bộ tính năng mà phần lớn người dùng chưa khai thác hết. Học kỹ phần này là đòn bẩy lớn nhất.

Projectsworkspace
Không gian làm việc có ngữ cảnh dùng chung. Mỗi project có custom instructions riêng (định nghĩa vai trò, định dạng đầu ra, ràng buộc) và knowledge (tài liệu nền). Mọi chat trong project kế thừa các thứ này — lý tưởng cho công việc lặp lại có khuôn mẫu (vd: dựng chuỗi bài giảng, báo cáo theo template). Tách biệt theo project, không lẫn ngữ cảnh.
Artifactsđầu ra sống
Cửa sổ bên cạnh hiển thị sản phẩm Claude tạo: tài liệu, code, biểu đồ, hoặc cả app HTML/React chạy được. Có thể lặp/sửa trực tiếp. Artifact còn hỗ trợ persistent storage (key–value) để làm app có lưu trạng thái như tracker, journal.
Stylesgiọng văn
Cấu hình phong cách viết để đầu ra luôn nhất quán (vd: súc tích, không bullet, giọng kỹ thuật). Đặt một lần, áp cho mọi phản hồi — khỏi nhắc lại "viết ngắn gọn" mỗi lần.
Memory + Past chatsliên tục
Memory rút trích thông tin bền vững từ lịch sử để giữ ngữ cảnh giữa các phiên (bật trong Settings). Search past chats cho phép tìm lại và tiếp nối hội thoại cũ. Hữu ích khi bạn liên tục nhắc tới "dự án của tôi" mà không muốn mô tả lại.
Web search + Researchtruy xuất
Web search lấy thông tin hiện tại kèm trích dẫn. Research (gói trả phí) đào sâu nhiều nguồn cho câu hỏi lớn rồi tổng hợp có dẫn nguồn — đúng loại việc như "bức tranh công nghệ X trên thế giới & VN" hay kiểm chứng số liệu báo cáo.
Code execution & tạo fileskills
Chạy code thật trong sandbox để phân tích dữ liệu, vẽ biểu đồ; và tạo file chuyên nghiệp — Word (.docx), PowerPoint (.pptx), Excel (.xlsx), PDF — qua bộ "skills" đóng gói best practice. Tải về hoặc đẩy lên Drive.
Connectors / MCPkết nối ngoài
Nối Claude với ứng dụng ngoài (Google Drive, Gmail, Calendar, Jira, Slack…) qua Model Context Protocol. Claude đọc/thao tác dữ liệu nơi nó đang nằm thay vì bắt bạn copy vào. Bật trong Settings hoặc thư mục connector.
Voice & visionđa phương thức
Nói chuyện bằng giọng và đưa ảnh/PDF vào để Claude đọc sơ đồ, ảnh chụp màn hình, biểu đồ, ảnh tài liệu. Hữu ích cho việc đọc figure trong paper hay debug từ screenshot.
Combo mạnh cho DS/AITạo một Project "Nghiên cứu của tôi" → custom instructions ghi rõ phong cách bảng/thuật ngữ Anh–Việt → bật memory → dùng code execution để EDA và tạo file để xuất báo cáo docx. Bốn tính năng ghép lại thành một quy trình một-cửa.
04

Bề mặt agent · cho kỹ sư

Claude Code

Công cụ lập trình agentic chạy ở terminal, IDE, desktop app, hoặc browser. Khác với autocomplete: nó hoạt động ở cấp dự án — đọc cả codebase, lập kế hoạch xuyên nhiều file, thực thi, chạy test, lặp khi lỗi. Bạn định nghĩa mục tiêu, nó làm phần còn lại.

Cài đặt & bề mặt

# macOS / Linux — script cài chính thức
curl -fsSL https://claude.ai/install.sh | bash

# Windows: chạy trong PowerShell (xem docs nếu gặp lỗi cú pháp)
# Bản cài native tự cập nhật nền; Homebrew có cask claude-code

# Dùng ngay trong thư mục dự án
claude
claude "thêm test cho module thanh toán rồi chạy"

Hỗ trợ CLI terminal, tích hợp VS Code/IDE, desktop app, và Claude Code Web. Phần lớn bề mặt cần subscription Claude hoặc tài khoản Console; CLI và VS Code còn hỗ trợ provider bên thứ ba (Bedrock, Vertex).

Cơ chế cốt lõi cần nắm

ngữ cảnh

CLAUDE.md

File markdown ở gốc repo, Claude đọc đầu mỗi phiên. Ghi coding standard, kiến trúc, thư viện ưu tiên, checklist review. Ngoài ra Claude tự xây auto memory: lưu lệnh build, insight debug… qua các phiên mà bạn không phải viết tay.

đóng gói

Skills & slash commands

Gói quy trình lặp lại thành lệnh dùng chung cho cả team: /review-pr, /deploy-staging. Một lần định nghĩa, cả nhóm gọi như chuyên gia có sẵn.

tự động

Hooks

Chạy shell command trước/sau hành động của Claude — ví dụ auto-format, chặn commit nếu lint fail. Biến quy ước thành ràng buộc thực thi.

song song

Sub-agents

Chia việc lớn cho nhiều agent con chạy song song với context riêng — review, sửa, test đồng thời thay vì tuần tự.

kết nối

MCP

Đọc design doc trong Drive, cập nhật ticket Jira, kéo dữ liệu Slack, hoặc gọi tooling nội bộ của bạn — ngay trong phiên code.

lịch & CI

Routines & GitHub Actions

Chạy theo lịch trên hạ tầng Anthropic (review PR mỗi sáng, phân tích CI fail ban đêm) — chạy cả khi máy bạn tắt. Tự động review & triage trong CI qua GitHub Actions / GitLab.

Chế độ "headless" — ghép vào pipeline

# Theo triết lý Unix: pipe vào, dùng cờ -p để chạy không tương tác
tail -200 app.log | claude -p "báo cho tôi nếu thấy bất thường"
git diff main --name-only | claude -p "review các file đổi về lỗ hổng bảo mật"
An toànMặc định Claude Code hỏi trước khi sửa file hoặc chạy lệnh. Nó làm trong môi trường của bạn, dùng công cụ của bạn — quyết định cuối cùng vẫn ở con người. Có chế độ phân quyền chi tiết cho autonomous mode. Hãy giữ thói quen review trước khi merge.

Bề mặt agent · việc tri thức

Claude Cowork

Sức mạnh agent của Claude Code, nhưng cho việc không-lập-trình và không cần terminal. Chạy trong Claude Desktop: bạn trỏ vào một thư mục, giao mục tiêu, nó tự lập kế hoạch và thực thi — giống giao việc cho một đồng nghiệp giỏi rồi để họ làm.

file thật

Truy cập file cục bộ

Đọc/sửa/tạo file trong thư mục bạn cấp quyền — không cần upload/download thủ công. Nó "làm" thay vì chỉ "mô tả cách làm".

điều phối

Sub-agent song song

Chia việc phức tạp thành nhiều luồng con chạy đồng thời; bạn theo dõi tiến trình và có thể chen vào chỉnh hướng bất cứ lúc nào.

đầu ra

Sản phẩm chỉn chu

Xuất Excel có công thức chạy được, PowerPoint, tài liệu định dạng. Soạn Markdown thì bôi đen → "Edit with Claude" để sửa tại chỗ.

web

Claude in Chrome (connector)

Bật Chrome như connector để Cowork thao tác web: bấm nút, điền form, chuyển tab — hoàn tất tác vụ cần truy cập web.

Việc Cowork làm tốt nhất

Dọn & tổ chức file: trỏ vào folder bừa bộn (drafts, downloads, attachment) → đổi tên theo nội dung, sắp xếp, khử trùng lặp, nổi bật cái cần.

Dựng báo cáo từ nguồn rời: đưa một bộ file nguồn → nó tổng hợp thành bản nháp có cấu trúc; phần còn lại của bạn chỉ là tinh chỉnh.

Số hoá việc lặt vặt: biến đống ảnh hoá đơn thành bảng chi phí; chuyển định dạng hàng loạt; quét dữ liệu/feedback mà thường bị bỏ qua.

Có hệ plugin việc tri thức (mã nguồn mở) bổ sung quản lý task, "workplace memory" để Claude học người/dự án/thuật ngữ của bạn, và dashboard trực quan — biến Claude thành đồng nghiệp hiểu ngữ cảnh thay vì chatbot.

Rủi ro cần biếtVì Cowork hành động trên file thật: prompt mơ hồ có thể gây hậu quả (vd xoá nhầm — nên Claude luôn hỏi quyền trước khi xoá vĩnh viễn). Còn rủi ro prompt injection: nội dung độc trong file/web có thể tác động hành vi agent. Đừng dùng cho dữ liệu bị quản lý chặt nếu chưa có kiểm soát phù hợp; app phải mở khi đang chạy task.
Khả dụngCowork chạy trong Claude Desktop (research preview), cho các gói trả phí (Pro, Max, Team, Enterprise). Kiểm tra bản desktop mới nhất tại claude.com/download.

08

Kỹ năng lõi

Prompting hiệu quả

Mọi bề mặt đều mạnh hơn nhiều khi bạn ra chỉ dẫn tốt. Đây là kỹ năng có đòn bẩy cao nhất và áp dụng ở mọi nơi.

Bảy nguyên tắc

01

Rõ & chi tiết

Nói thẳng bạn muốn gì, ràng buộc gì, đối tượng đọc là ai. Mơ hồ vào → mơ hồ ra. "Cải thiện hàm này về tốc độ, giữ API cũ" tốt hơn "làm cho tốt hơn".

02

Cho ngữ cảnh

Dán schema, ví dụ dữ liệu, thông báo lỗi, ràng buộc môi trường. Claude suy luận tốt hơn nhiều khi thấy bối cảnh thật thay vì đoán.

03

Dùng ví dụ (few-shot)

Một cặp input→output mẫu định hình đầu ra mạnh hơn cả đoạn mô tả dài. Thêm ví dụ "xấu" để chỉ rõ cái cần tránh.

04

Khuyến khích suy luận từng bước

Với bài toán khó, yêu cầu "nghĩ từng bước trước khi trả lời" hoặc tách kế hoạch khỏi thực thi giúp kết quả chính xác hơn.

05

Cấu trúc bằng thẻ XML

Bọc các phần bằng thẻ như <data>, <yeu_cau>, <vi_du> để Claude phân biệt rạch ròi đâu là dữ liệu, đâu là chỉ dẫn.

06

Chỉ định định dạng & độ dài

"Trả về bảng 3 cột", "tối đa 200 từ", "chỉ code, không giải thích". Nói rõ hình thức đầu ra để khỏi phải sửa lại.

07

Lặp & tinh chỉnh

Coi prompt như vòng lặp: ra kết quả → chỉ ra chỗ chưa đúng → tinh chỉnh. Thường nhanh hơn cố viết một prompt hoàn hảo ngay.

Ví dụ: từ yếu đến mạnh

# YẾU
viết hàm đánh giá model

# MẠNH
<vai_tro> Bạn là ML engineer, dữ liệu phân loại nhị phân mất cân bằng (~5% lớp dương). </vai_tro>
<nhiem_vu> Viết hàm Python tính precision, recall, F1 và specificity theo từng lớp,
trả về dict, có docstring và type hint, không phụ thuộc sklearn. </nhiem_vu>
<dinh_dang> Chỉ trả code trong một block, kèm 1 ví dụ chạy ở cuối. </dinh_dang>

Tài liệu prompt engineering đầy đủ: docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview

09

Theo vai trò

Công thức cho DS/AI engineer & Web dev

Tính năng chỉ hữu ích khi ghép vào quy trình thật. Dưới đây là các playbook bám sát công việc của bạn.

Data Scientist / AI engineer

EDA & notebook

Khám phá dữ liệu

Upload CSV → dùng code execution để thống kê, vẽ phân phối, phát hiện outlier/missing. Yêu cầu xuất biểu đồ và bảng tóm tắt. Hợp ở Chat; nếu là nhiều file rời, dùng Cowork.

đánh giá model

Metric & chẩn đoán

Dán confusion matrix / log training → nhờ giải thích precision–recall vs specificity–sensitivity, chẩn đoán overfit/leak, đề xuất bước tiếp. Yêu cầu code metric kèm test nhỏ.

RAG & agent

Dựng & tinh chỉnh

Thiết kế pipeline chunking/embedding/retrieval; với hệ thống thật, dùng Claude Code để cắm vào repo, viết eval, đo. Dùng API khi sản phẩm hoá.

đọc paper

Tiêu hoá tài liệu

Đưa PDF + hỏi đóng góp chính, hạn chế, cách tái lập. Dùng vision để đọc figure. Nhờ tóm tắt cho slide báo cáo lãnh đạo (kèm mốc thời gian & nguồn).

synthetic data

Xử lý mất cân bằng

Bàn chiến lược sinh dữ liệu/cân bằng lớp hiếm, so sánh phương pháp, sinh code thử nghiệm và biểu đồ specificity/sensitivity để đánh giá công bằng giữa hai lớp.

báo cáo

Từ phân tích → deliverable

Kết quả phân tích → xuất docx/pptx/xlsx qua skills, hoặc dựng tài liệu HTML trực quan. Đây chính là quy trình một-cửa từ dữ liệu tới sản phẩm gửi đi.

Mẹo độ tin cậyVới mọi con số từ web, bật web search/Research và yêu cầu trích nguồn; nhờ Claude kiểm chứng chéo số liệu trong slide trước khi trình lãnh đạo, ghi rõ mốc thời gian vì lĩnh vực AI thay đổi nhanh.

Web developer

khởi tạo

Scaffold & component

Mô tả component/trang → nhận code chạy được (xem trước qua Artifacts). Cho UI hoàn chỉnh hơn, dùng Claude Design rồi bàn giao sang Code.

sửa lỗi

Debug có ngữ cảnh

Dán stack trace + đoạn code + hành vi mong đợi. Trong repo thật, để Claude Code tự đọc, sửa nhiều file, chạy test, lặp tới khi xanh.

refactor

Đổi mới an toàn

Giao mục tiêu ("tách logic ra hook, giữ API"), thêm test trước. Dùng hooks để ép lint/format, sub-agents để làm song song nhiều module.

design→code

Prototype tới production

Đi theo chuỗi: ý tưởng → Design (prototype, bám design system) → handoff bundle → Code dựng thật. Khoảng cách prototype–production thu lại còn vài prompt.

test & docs

Phủ test & tài liệu

Sinh unit/integration test, sinh README/ADR từ code. Đặt checklist review trong CLAUDE.md để chuẩn hoá chất lượng cả team.

CI

Tự động hoá

Cắm GitHub Actions để Claude review PR & triage issue; routines chạy audit phụ thuộc hàng tuần, phân tích CI fail ban đêm.

10

Xây trên Claude

API & Claude Platform

Khi bạn muốn nhúng Claude vào sản phẩm của mình. Đây là phần tóm tắt định hướng — chi tiết ở docs.claude.com.

Năng lực API cần biết

nền

Messages API

Điểm cuối hội thoại chuẩn. Model string: claude-opus-4-8, claude-sonnet-4-6, claude-haiku-4-5. Không trạng thái — gửi đủ ngữ cảnh mỗi lần gọi.

công cụ

Tool use & server tools

Function calling để Claude gọi tool của bạn; sẵn các server tool: web search, web fetch, code execution, tool search, memory.

đầu ra

Structured outputs

Buộc đầu ra theo JSON/schema để parse an toàn — quan trọng khi nối Claude vào UI hay pipeline dữ liệu.

suy luận

Extended thinking

Bật suy luận sâu cho bài toán khó; kiểm soát ngân sách "thinking" theo nhu cầu chính xác vs chi phí.

tối ưu chi phí

Prompt caching

Cache phần ngữ cảnh lặp (system prompt, tài liệu): trả full giá một lần, lần sau giảm tới ~90%. Đòn bẩy lớn cho app có context cố định.

khối lượng

Batch API

Xử lý không gấp trong tối đa 24h, giảm 50% giá token — hợp pipeline xử lý tài liệu/dữ liệu hàng loạt qua đêm.

realtime

Streaming

Trả token theo luồng cho UX phản hồi tức thì.

agent

Agent SDK

Bộ khung dựng agent riêng — cùng kiến trúc đứng sau Code/Cowork — để bạn tự xây tác nhân chuyên biệt.

# Mẫu tối giản (Python)
import anthropic
client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role":"user","content":"Tóm tắt log này…"}],
)
print(msg.content)
Phân biệt billingSubscription (Free/Pro/Max/Team/Enterprise) và API là hai đường thanh toán khác nhau. Dùng app thì theo subscription; nhúng vào phần mềm của bạn thì trả theo token qua API. Đừng nhầm hai cái khi tính chi phí.
11

Quan trọng cho môi trường doanh nghiệp

Bảo mật & dữ liệu

Nếu bạn làm trong ngân hàng/tài chính hay xử lý dữ liệu nhạy cảm, phần này đáng đọc kỹ.

huấn luyện

Dữ liệu có bị dùng để train?

Với API: input/output không dùng để huấn luyện theo mặc định, log giữ ngắn (khoảng 7 ngày) rồi xoá. Với sản phẩm tiêu dùng (Free/Pro/Max): người dùng có thể opt-in — kiểm tra cài đặt nếu không muốn.

nhạy cảm

Trước khi dán

Che (redact) credential, mật khẩu, khoá API, IP nội bộ, PII khách hàng trước khi đưa vào. Nội dung vẫn đủ để Claude hỗ trợ mà không lộ bí mật thật.

agent

Prompt injection

Với Cowork/Code/Chrome, nội dung độc nhúng trong file hoặc trang web có thể cố điều khiển agent. Hạn chế quyền, duyệt hành động, không trỏ agent vào nguồn không tin cậy.

tổ chức

Kiểm soát Enterprise

SSO/SCIM, audit log, kiểm soát lưu trữ & residency, tắt web search cho Cowork/Chat ở cấp tổ chức, quản lý quyền tính năng và chi tiêu.

Quy tắc vàngCoi mọi thứ bạn dán như có thể bị lưu tạm. Với tài liệu được bảo vệ bằng nhãn IRM/Purview của công ty, Claude trong môi trường ngoài không giải mã được — xử lý các thao tác đó trên máy đã đăng nhập tài khoản tổ chức.
